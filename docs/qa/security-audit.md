# Конфиденциальность при аудите BBKB

Проверялись локальная сборка и переданный APK. На AVD использованы синтетические тексты. Ключи подписи и исходный APK отсутствуют среди отслеживаемых Git-файлов. Эталонный APK подписан отдельным сертификатом, проверенным `apksigner`.

| Область | Результат |
| --- | --- |
| История буфера | Найдено сохранение файлов при выключенной истории и после очистки. Исправлена последовательность захвата, удаление файлов и чистка потерянных объектов. |
| Дисковый лимит | В полезную нагрузку включены файлы и миниатюры обеих групп. Фактическая запись потока ограничена. Учёт полного каталога с метаданными и временными стадиями требует проверки. |
| URI изображений | Относительный путь проверяется перед чтением, подсчётом и удалением. Передача идёт через FileProvider и временное разрешение `commitContent`. Получение и отзыв разрешения на Android 17 остаются отдельным сценарием. |
| Logcat | DEBUG пишет введённые слова, контекст и результаты XT9. Работа релизной сборки и отсутствие чувствительного текста в её журнале требуют проверки. |
| Защищённые поля, резервные копии, сеть | Нужен сквозной тест паролей, флагов чувствительности, состава резервной копии и сетевых запросов. |
| Атрибуция переносимых данных | Проверена часть источников. Происхождение разговорного пакета и полное восстановление рецепта корпуса требуют подтверждения. |

[Реестр дефектов](bug-register.md) [Источники данных](../dictionaries.md)

Статически сверены объединённый release-манифест и граф зависимостей. FileProvider закрыт для прямого экспорта и поддерживает предоставление URI-разрешений. Правила резервного копирования включают пользовательский словарь и настройки, excludes применяются к истории буфера и данным DLM. Фактическое восстановление и отзыв URI-разрешений остаются открыты.
