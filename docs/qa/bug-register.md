# Реестр дефектов BBKB

Исходная ревизия форка — `8f76af7e`. Коммит исходного BBKB — `ba8b9d0d`.

| ID | Приоритет | Наблюдение и первопричина | Исправление и проверка |
| --- | --- | --- | --- |
| BBKB-001 | P1 | В чистом клоне Gradle Wrapper падал с ClassNotFoundException. Общее правило для JAR исключало Wrapper. | Возвращён официальный JAR 9.6.0. SHA-256 сверена с Gradle. Новый запуск выполнил clean и собрал оба модуля. |
| BBKB-002 | P2 | Тест публикации ожидал minSdk 23. Приложение и опубликованный манифест используют 26. | Синхронизировано ожидание. 68 тестов Python прошли. |
| BBKB-003 | P1 | В корзине «при» слово «привести» находится в строке 81. Поиск достигал лимита просмотренных строк до проверки точного префикса. | Сканирование прекращается после нужного числа совпадений. Окно поиска с опечатками сохранено. JUnit падал на исходнике и прошёл после исправления. |
| BBKB-004 | P2 | Частоты биграмм могли вытеснить результат точного контекста. Токенизация теряла «I» и «в». | Триграмма имеет приоритет, биграмма заполняет оставшиеся места. JUnit проверяет оба пути и границы предложения. |
| BBKB-005 | P1 | Отключённая история успевала записать изображение. Удаление записи, истечение срока и очистка оставляли изображения. Повторные изображения сравнивались по пустому тексту. | Захват проверяет настройку до записи. Изображения и миниатюры удаляются, потерянные файлы чистятся при загрузке. Изображения исключены из дедупликации текста. |
| BBKB-006 | P1 | В лимит 256 МиБ учитывались только незакреплённые строки. Запись большого изображения читала весь поток до применения лимита. | Закреплённые записи учитываются в общем лимите полезной нагрузки. Слишком большой поток прерывается при сохранении. Дисковый размер с JSON и временными файлами требует отдельной проверки. |
| BBKB-007 | P2 | CRLF ломал запуск скриптов из WSL и сравнение с эталонами. Под C11 отсутствовали объявления POSIX. | Скрипты получают LF. Сравнение игнорирует только CR в конце строки. Драйверы запрашивают POSIX 2008. |
| BBKB-008 | P1, открыт | Эталон recall_top8_golden.txt расходится с результатом WSL на x86_64, в том числе с Clang. | Эталон и рабочее ранжирование сохранены. Причину расхождения нужно подтвердить. |
| BBKB-009 | P2 | Базовые флаги и двунаправленные стрелки отсекались фильтром компонентов. В сетке отсутствовали добавления Emoji 17/18. | Уточнён фильтр. Добавлены базы и варианты из официального Unicode. Отрисовка зависит от системного шрифта. |
| BBKB-010 | P1, открыт | В DEBUG есть сообщения Logcat с текстом композиции, контекстом, результатами XT9 и обучения. | Релизный APK и сетевой трафик требуют отдельной проверки. |
| BBKB-011 | P1 | Панель перевода показывала «Нет поля ввода» в открытом редакторе. Контекст панели не гарантировал доступ к сервису IME. Закрытие также не инвалидировало результаты и штрихи. | Контроллер передаёт действующий сервис. Результаты проверяют сессию, поколение и связь с редактором. Офлайн-перевод и вставка на финальном APK прошли. |
| BBKB-012 | P1 | Команда «Слово» удаляла до 16 символов. | Команда передаёт Ctrl+Left парой событий. Тест проверяет события и отсутствие операций удаления. |
| BBKB-013 | P2 | В RU отсутствовали 10 строк, а панель правки использовала русский текст напрямую из кода. | Добавлены ресурсы, панель правки переключается по локали. Строки других экранов и локалей требуют завершения. |
| BBKB-014 | P2 | Два теста зависели от разделителя файлов и часового пояса хоста. | Используется сравнение компонентов пути. Тест имён резервных копий проверяет UTC и Москву. |
| BBKB-015 | P1 | Изображения выглядели как пустые текстовые записи. Полоса правки находилась в другом контейнере, чем список и пустое состояние. | Добавлены миниатюры и подпись. Полоса размещена в контейнере списка. Тест фиксирует правило расположения, harness подтвердил доставку PNG на Android 15. |
