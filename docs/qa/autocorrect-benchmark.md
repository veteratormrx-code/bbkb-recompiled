# Корпус интеллектуального ввода

[Корпус CSV](autocorrect-corpus.csv) содержит **1138** сценариев, 570 RU и 568 EN. Есть правильные слова, четыре вида синтетических опечаток, примеры из задания и сохраняемые имена, сленг и технические термины. Сценарий задаёт ввод и ожидаемый результат. Синтетические варианты, совпавшие с другими допустимыми словами, требуют разметки неоднозначности перед расчётом метрик.

```powershell
python tools/qa/build_autocorrect_corpus.py docs/qa/autocorrect-corpus.csv
```

Для трёх клавиатур используется один редактор на одном AVD. Кандидаты считываются до пробела для Top-1 и Top-3. Текст после пробела измеряет автозамену. Backspace после замены проверяет отмену. Правильные и защищённые слова дают знаменатель для ложных замен.

| Показатель | Upstream | 4PDA | Форк |
| --- | --- | --- | --- |
| Top-1 / Top-3 по корпусу | NOT RUN | NOT RUN | NOT RUN |
| Исправление опечаток и ложные замены | NOT RUN | NOT RUN | NOT RUN |
| Сохранение правильных слов и отмена | NOT RUN | NOT RUN | NOT RUN |
| Качество подсказок контекста RU/EN | NOT RUN | NOT RUN | NOT RUN |
