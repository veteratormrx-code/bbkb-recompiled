# Воспроизводимые сценарии

| Сценарий | Действие | Проверяемое состояние |
| --- | --- | --- |
| IME-SMOKE | Выбрать проверяемый IME и открыть пустой `plain` harness. Тапнуть `b` дважды, ещё раз и Backspace. | Текст `bb`, `bbb`, `bb`. Выбранный IME остаётся активным, процесс жив. |
| WEB-NUM | Коснуться `web number`, нажать минус, 1, 2, точку и 5. | Цифровая раскладка и значение `-12.5` в HTML-поле. |
| ML-OFFLINE | Загрузить EN→RU. Тапами набрать `cat`, отключить сеть, открыть перевод и вставить результат. Затем поменять направление. | `cat → кошка` с вставкой в редактор и `кошка → cat` в превью. |
| RUL1 | Запустить `count_forms.py` с эталонным APK и JSON. | Проверка структуры, SHA-256 всех пяти пакетов и фактическое число уникальных форм. |
| MIG-PREF | Установить совместимо подписанный upstream debug, записать тестовые настройки, выполнить `install -r`. | Те же четыре значения после замены APK. |
