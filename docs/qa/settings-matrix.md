# Проверка настроек

[Инвентаризация статических деклараций](settings-static.csv) содержит 81 вызов настройки с файлом, строкой и выражениями для ключа и значения по умолчанию. Выражения вроде `NumberRow.PREF` требуют сверки с классом-владельцем. Список охватывает статические вызовы `boolPref`, `intPref`, `intPrefRes` и `stringPref`. Он не охватывает динамические параметры, все элементы навигации и хранилища, созданные вне этих вызовов.

| Проверка | Результат |
| --- | --- |
| Статическая полнота русских строк | При первом прогоне отсутствовали 10. Добавлены строки панели правки, перевода и рукописного ввода. |
| Ресурсы региональных локалей | Полный JVM-прогон обнаружил 73 папки с пропущенными строками. Тест полноты сохранён. |
| Палитра OLED | JUnit `OledPaletteTest` прошёл. |
| Поиск, независимые значения, применение каждой настройки, перезапуск и миграция | NOT RUN по полной матрице. |
| Физическая клавиатура, TalkBack, ширины от 320 до 720 dp | Полная проверка не завершена. |
