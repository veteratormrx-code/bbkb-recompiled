# Замена тестовой сборки

Upstream debug из коммита `ba8b9d0d` переподписан существующим локальным debug-ключом форка для теста на изолированном Android 15. У пары одинаковые `dev.bbkb.ime.debug`, сертификат и versionCode 1442. Основанный на Android `install -r` сценарий проверяет сохранение настроек при замене кода в установленном пакете.

Сохранились стиль `classic`, схема `dark`, выключенный цифровой ряд и выключенная автокапитализация. [До](../testing/artifacts/audit-2026-11-24/migration-before.json) [После](../testing/artifacts/audit-2026-11-24/migration-after.json)

Переход между разными versionCode, релизная подпись, пользовательские словари, буфер и загруженные модели требуют отдельных проверок.
