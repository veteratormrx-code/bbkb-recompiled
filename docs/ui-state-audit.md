# Аудит слоёв клавиатуры

Подсказки над клавишами рисует `FlickSuggestionView`. Это отдельный слой поверх всего кадра, не часть панели.

Пока слой не подавлен, любое новое обновление XT9 снова показывает слова, даже если открыта другая панель. Поэтому разового `hide()` недостаточно.

Подавление включается, когда открыты:

- буфер, голос, цифровая панель (`setFlickSuggestionVisibility`);
- правка, перевод, рукопись (`ToolBoardController`);
- смена языка и панель акцентов (`AuxBarManager`).

Пока флаг стоит, `showSuggestions` сразу выходит. После закрытия панели следующее обновление снова рисует слова.

Это не покрывает каждый будущий режим автоматически: новый режим должен вызвать то же подавление. Отдельного единого автомата «один режим — один набор слоёв» в BBKB нет, видимость по-прежнему собирается из нескольких контроллеров.
