# Компактная панель инструментов

Стрелка слева открывает и закрывает ряд иконок в той же высоте полосы. По умолчанию ряд свёрнут.

Режим хранится в `pref_toolbar_mode`:

- `collapsed` — ряд спрятан, стрелка его открывает. Это значение по умолчанию.
- `pinned` — ряд остаётся открытым, стрелка его не сворачивает.
- `hidden` — полоса не занимает место. Вернуть её можно в настройках: Ввод → Вспомогательный ввод → Режим панели.

Где показывать подсказки (`pref_suggestion_place`):

- `classic` — слова над клавишами, верхняя строка их не дублирует.
- `strip` — только верхняя строка.
- `both` — и над клавишами, и в строке.
- `none` — обычные подсказки не рисуются.

Порядок инструментов — `pref_toolbar_order`. Если строка пустая, сначала идут буфер, эмодзи, правка, перевод и голос, затем рукописный ввод и цифровая панель. Сколько иконок видно, зависит от ширины экрана. Остальные открываются кнопкой «Ещё» списком поверх клавиш, не отдельным приложением.

Настройки стоят в существующем экране вспомогательного ввода и попадают в поиск.

Не сделано: перетаскивание порядка, живое превью клавиатуры, отдельный жест возврата из полностью скрытого режима кроме настроек, анимация 100–180 мс, автоматическое сворачивание на каждую букву, сравнение со скриншотами SwiftKey.
