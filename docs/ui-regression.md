# Регрессия интерфейса

[Текущий сравнительный прогон](qa/visual-comparison.md) включает реальные кадры всех шести тем на Android 17 и измерения RGB двух OLED-стилей.

Дата: 24.11.2026. Эмулятор Android 17 с окном, harness `dev.bbkb.ime.harness`.

| Сценарий | Статус | Что видно |
| --- | --- | --- |
| Буквенный ввод, OLED, ряд 1–0 | Проверено кадром | `docs/testing/artifacts/number-row.png` и `oled-vkb.png`: чёрная сетка, ряд цифр над буквами, подсказки на буквах |
| Набор `bb` | Проверено logcat | `XT9WORDS inline='bb'`, FATAL нет |
| Подсказки поверх панели правки | Исправление в коде | `FlickSuggestionView.setSuppressed` не даёт новому ответу XT9 снова нарисовать слова, пока панель, смена языка или акценты открыты. Повторный кадр после правки не снят |
| OLED без разделителей | Не подтверждено | Кадр `oled-seamless.png` показал Gboard |
| Эмодзи, буфер, голос, автозаполнение, альбом, настройки по разделам | Не пройдено | Отдельных кадров нет |
| Сравнение с чистым BBKB и APK 4pda | Не сделано | Оба установлены или дерево upstream лежит в `c:\work\bbkey\bbkb-upstream`, сценарии не прогнаны |

Пока режим — обычные буквы, подсказки над клавишами должны оставаться. Их отсутствие нужно только на чужой панели.
