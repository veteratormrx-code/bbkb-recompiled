# Конфиденциальность

Что есть в коде и не проверялось отдельным сценарием на эмуляторе:

- Лексикон и фразы не вызываются, если у `SuggestionEngine` включён `mBlockAutoCorrect`.
- Буфер по-прежнему не пишет sensitive-клипы и не пишет ничего при `IME_FLAG_NO_PERSONALIZED_LEARNING`.
- Картинки лежат в `filesDir/clipboard_images`. Наружу отдаются через неэкспортируемый FileProvider на время `commitContent`.
- Удаление записи удаляет файл и `.thumb`.
- Новый сетевой путь набора нет. Сеть нужна только кнопке скачивания модели ML Kit.

Не проверено: резервная копия истории, парольное поле на живом экране, отсутствие текста в logcat при обычном наборе (в этом прогоне logcat содержит введённое `bb`, потому что XT9 сам пишет `inline='bb'` в DEBUG).
