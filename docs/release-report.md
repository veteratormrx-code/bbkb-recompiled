# Отчёт о проверке

Последний статус приёмки — **NO-GO**. На отдельном Android 17 AVD выполнен повторный сравнительный прогон, собраны тестовые APK и найдены блокирующие проверки. [Текущая приёмка](qa/final-acceptance.md) [Результаты](qa/test-results.md)

## Предыдущий прогон

Дата: 24.11.2026. Эмулятор с окном: `Android Emulator - bbkb_api37:5554`, Android 17, ABI x86_64, Google Play.

## Что подтверждено командами

- Сборка debug прошла. В APK только `lib/arm64-v8a`.
- Установлены наша клавиатура, harness и APK 4pda.
- Процесс `dev.bbkb.ime.debug` жив. В logcat есть `XT9WORDS` и `XT9KDB` для `qwerty`. ARM-переводчик эмулятора загружает нативный движок.
- Пока AVD сообщает аппаратную клавиатуру, BBKB считает устройство PKB и не показывает сетку (`mainKbShowing=false` в `BBKBdiag`). Для экранной сетки на debug-сборке включён `debug_force_vkb_mode`.
- Кадр `docs/testing/artifacts/oled-vkb.png`: чёрная сетка с разделителями, в поле текст `bb`, подсказки XT9, процесса нет в FATAL.
- Память процесса сразу после этого: TOTAL PSS 159 530 КБ, Native Heap 38 603 КБ (`dumpsys meminfo`).
- Пересчёт словоформ: common 48 689, conversational 700, opencorpora 1 327 062, spelling 2 367 127, unimorph 12 712, объединение без дублей **3 708 431**.

## Что не подтверждено

- OLED без разделителей на нашей клавиатуре. Последний кадр `oled-seamless.png` — это Gboard.
- Панели перевода, рукописи и правки не открыты тапом. Код в меню есть.
- Скачивание моделей ML Kit, вставка картинки, WebView number, голос, автозаполнение, корпус из 1000 фраз, p95 подсказок, сравнение с upstream и 4pda.
- Релизный ключ подписывает текущий debug-APK для постоянной подписи. Это не отдельная release-сборка с R8.

Статус релиза: не готов к ежедневному использованию как замена 4pda-мода.
