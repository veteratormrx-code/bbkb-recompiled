# Словари

## Перепроверка файлов форка и эталонного APK

Команда `python tools/dictionaries/count_forms.py app/src/main/assets/bbmodern --reference-apk BlackBerryKeyboard-mod-Android17.apk --json` прочитала 22 128 блоков RUL1 во всех пяти словарях. Заголовки, границы блоков, целостность потоков zlib, UTF-8 и соответствие слов префиксам прошли проверку. Все пять файлов побайтно совпали с ресурсами переданного APK. Машиночитаемый результат включает SHA-256 каждого словаря и количество записей с нулевой частотой. [Результат](testing/artifacts/audit-2026-11-24/dictionaries.json)

В файлах 3 756 290 записей. После объединения одинаковых строк остаётся 3 708 431 словоформа, а после приведения к регистру поиска и свёртки «ё» → «е» — 3 606 701 формы. Между словарями 47 859 повторных вхождений. Только `ru-common.bbd` из пяти файлов содержит положительные частоты. Проверка структуры подтверждает содержимое пакетов. Качество ранжирования проверяется отдельно при наборе.

Индексы фраз воспроизвелись из 29 русских и 26 английских TSV-шардов эталонного APK. Сравнение содержимого с учётом платформенных концов строк прошло для обоих индексов. Исходные выгрузки Tatoeba и правила построения шардов в репозитории отсутствуют. [Результат](testing/artifacts/audit-2026-11-24/phrases.json)

### Происхождение и лицензии

| Пакет | Сверка первоисточника |
| --- | --- |
| `ru-common.bbd` | Атрибуция в ресурсе связывает его с FrequencyWords Russian 2018 и сообщает CC BY-SA 4.0 для адаптированных данных. Скрипт подготовки и точная версия входного файла не подтверждены. [Источник](https://github.com/hermitdave/FrequencyWords/tree/master/content/2018/ru) |
| `ru-spelling.bbd` | RusSpell 1.0.9 подтверждает MPL 2.0. Источник публикует 2 367 159 форм в CSpell, в нашем RUL1 — 2 367 127. Для воспроизводимой поставки нужны исходные материалы и точные фильтры преобразования. [Источник](https://github.com/Goudron/ru-spelling-dictionary/releases/tag/v1.0.9) |
| `ru-opencorpora.bbd` | Версия упаковки `pymorphy3-dicts-ru 2.4.417150.4580142` существует. Переданная атрибуция указывает CC BY-SA 3.0 для данных OpenCorpora. Генерация в RUL1 из опубликованного пакета не выполнена. [Пакет](https://pypi.org/project/pymorphy3-dicts-ru/2.4.417150.4580142/) |
| `ru-unimorph.bbd` | UniMorph указывает Wikipedia и CC BY-SA 3.0. Атрибуция APK упоминает Wiktionary, поэтому происхождение адаптации требует сверки. [Источник](https://github.com/unimorph/rus) |
| `ru-conversational.bbd` | В APK есть 700 форм. Точный источник именно этого набора и его отдельные условия распространения не установлены. |
| `phrases-*.idx` | Tatoeba указывает CC BY 2.0 FR для текстовых выгрузок и CC0 для части предложений. Для оценки полной цепочки атрибуции нужны снимок выгрузки и рецепт преобразования до TSV-шардов. [Источник](https://en.wiki.tatoeba.org/articles/show/using-the-tatoeba-corpus) |

## Предыдущий прогон

Пересчёт 24.11.2026, скрипт `tools/dictionaries/count_forms.py` по файлам в `app/src/main/assets/bbmodern`:

| Файл | Строк | Уникальных форм |
| --- | ---: | ---: |
| ru-common.bbd | 48 689 | 48 689 |
| ru-conversational.bbd | 700 | 700 |
| ru-opencorpora.bbd | 1 327 062 | 1 327 062 |
| ru-spelling.bbd | 2 367 127 | 2 367 127 |
| ru-unimorph.bbd | 12 712 | 12 712 |
| Все вместе |  | **3 708 431** |

Цифра совпадает с заявлением поста 4pda. Это пересчёт уже собранных `.bbd` из APK, не сборка из Hunspell/OpenCorpora с нуля. Генератор исходных корпусов в дереве не запускался: в APK есть только `make_lexicons.py` и готовые пакеты. Лицензионные тексты лежат рядом с файлами (MPL 2.0, CC BY-SA 3.0, CC BY-SA 4.0) и взяты из того же APK, а не сверены с сайтами правообладателей в этом прогоне.

Фразы пересобраны `tools/dictionaries/build_phrases.py`: ключ — одно или два предыдущих слова, у продолжения есть счётчик, повтор ключа суммируется, а не отбрасывается. Получилось 197 067 русских и 263 875 английских контекстов. В этих шардах число строк совпало с числом ключей, то есть дублей ключей в исходных TSV не было.

Поиск словоформы при опечатке в первых трёх буквах смотрит соседние корзины ЙЦУКЕН (`lookupWithPrefixTypos`). На эмуляторе качество этого поиска не измерялось.
