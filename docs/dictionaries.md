Цифра совпадает с заявлением поста 4pda. Это пересчёт уже собранных `.bbd` из APK, не сборка из Hunspell/OpenCorpora с нуля. Генератор исходных корпусов в дереве не запускался: в APK есть только `make_lexicons.py` и готовые пакеты. Лицензионные тексты лежат рядом с файлами (MPL 2.0, CC BY-SA 3.0, CC BY-SA 4.0) и взяты из того же APK, а не сверены с сайтами правообладателей в этом прогоне.

Фразы пересобраны `tools/dictionaries/build_phrases.py`: ключ — одно или два предыдущих слова, у продолжения есть счётчик, повтор ключа суммируется, а не отбрасывается. Получилось 197 067 русских и 263 875 английских контекстов. В этих шардах число строк совпало с числом ключей, то есть дублей ключей в исходных TSV не было.

Поиск словоформы при опечатке в первых трёх буквах смотрит соседние корзины ЙЦУКЕН (`lookupWithPrefixTypos`). На эмуляторе качество этого поиска не измерялось.
