# Наш форк и оригинальный BBKB

Сравнение на 25 ноября 2026 года. Оригинал в этом отчёте — upstream BBKB `lhmb2025/bbkb-recompiled` на ревизии `ba8b9d0d`. Для проверки на Android 17 использовался его опубликованный APK `5.0.0-beta.29`. Наш форк описан на ревизии `804defc7`. [Аудит оригинала](../audit/upstream-bbkb.md) · [Отдельное сравнение с 4PDA APK](apk-mod-user-report.md)

## Что подтверждено на Android

- На одном Android 17 оригинал и форк прошли ввод `bb`, `bbb` и Backspace. Оригинал проверялся опубликованным релизом, форк — отдельным debug-пакетом. [Оригинал](../testing/artifacts/audit-2026-11-24/api37/upstream/results.json) · [Форк](../testing/artifacts/audit-2026-11-24/api37/fork/results.json)
- В форке подтверждены ввод `-12.5` в числовом поле WebView, обе OLED-темы, офлайн-перевод RU↔EN и вставка изображения в совместимый редактор на Android 15. [Результаты](../qa/test-results.md) · [Буфер обмена](../qa/clipboard-report.md)
- Сопоставимого полного RU-прогона оригинала и форка пока нет. Данные проверок подтверждают перечисленные сценарии. Они не устанавливают общее преимущество по точности и скорости. [Сравнение подсказок](../qa/autocorrect-benchmark.md)

## Установка и данные

Оригинал и release-форк используют пакет `dev.bbkb.ime` для `arm64-v8a`. Обновление поверх установленной сборки возможно при совместимой подписи и подходящем коде версии. Debug-форк `dev.bbkb.ime.debug` устанавливается рядом и имеет отдельные настройки и словари. Сохранение четырёх настроек проверено на совместимо подписанных debug APK. Полный перенос истории, словаря и моделей для release остаётся открытым. Публичный релиз форка ещё не прошёл полную приёмку.
