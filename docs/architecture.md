# Архитектура

Основа — BBKB `dev.bbkb.ime`. XT9 и PKB-профили не удалялись.

Поток подсказок: снимок набора идёт в `SuggestionEngine` на потоке движка, XT9 остаётся источником, затем для кириллицы добавляется `ModernLexicon`, а в режиме предсказания — `PhrasePredictions` по одному или двум предыдущим словам из `getContextBefore()`.

Буфер считает байты по длине файла и миниатюры, лимит незакреплённых записей 200, бюджет 256 МиБ.

OLED — два стиля `KeyboardColorManager`: `oled` и `oled_seamless`. Фон и клавиши `#000000`. Разделители — флаг `StyleSpec.drawKeySeparators`.

Панели правки, перевода и рукописи — один `ToolBoardView` на клавиатуре. Его открывают клавиши меню `-47`, `-48`, `-49`. На эмуляторе открытие не подтверждено.

Эмулятор с аппаратной клавиатурой определяется как PKB. Экранная сетка на debug-сборке появляется только с `debug_force_vkb_mode`.
